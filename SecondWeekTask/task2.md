    package main

    import "fmt"

    func Counter() func() int {
      	n := 0
      	return func() int {
    		n++
    		return n
    	}
    }

    func main() {
    	f := Counter()
	    for i := 0; i < 10; i++ {
	    	fmt.Println(f())
    	}
    }

# 笔记：
头一次在println中打印函数，打印的是函数的内存地址。

运行结果未符合预期我进行了搜索发现Counter()返回的是一个函数类型的值，打印出来的是函数的内存地址，而不是函数的返回值。

第二次尝试中打印的全为1，我没有搜到为什么。


随询问了ai，ai告诉我Counter()返回的是一个函数类型的值，

每次调用Counter()都会创建一个新的闭包函数，并且每个闭包函数都有自己的独立的变量n。

因此，每次调用Counter()都会返回一个新的闭包函数，这个闭包函数的n变量都是从0开始的，所以每次调用Counter()()都会返回1。

这说明我的闭包没有学的太好，。。于是我精进了一下下（也没有太多精进，主要是理解了闭包的概念）

闭包是一个函数，它可以访问并操作其外部函数的变量，即使外部函数已经返回。
